# Learn Japanese from screenshots with Quik

### What is Quik?

Quik is a lightweight tool to translate & explain Japanese from screenshots, powered by Gemini.

### Why use Quik?

1. Quik can translate *and* teach. AI\* understands context and can often give better, more natural translation.
2. Quik is quick. Use shortcuts to translate from clipboard, then bring up the translation instantly.  
3. Quik is free. As long as Gemini API remains free, Quik will be free too.  
4. Quik is seamless. Built with Tauri, Quik is tiny, fast, and won’t slow you down.

\*AI as in LLM, such as Gemini

### Why Gemini?

Because Gemini API is currently free.

### Get started in 3 steps

1. Download the latest version in **Releases**.
2. Enter your API key. If you don’t have one, get one for free at **aistudio.google.com**.  
3. Begin your first translation.
